# Customize Your Squad

Your squad evolves with your project. Use these commands anytime:

| Action | Command |
|--------|---------|
| **Add Member** | `Squad: Add Member` — pick a role, get an agent scaffold |
| **Remove Member** | `Squad: Remove Member` — select from current roster |
| **Edit Member** | `Squad: Edit Member` — update role, charter, status, or notes |
| **Open Team File** | `Squad: Open Team File` — edit the Markdown directly |

All changes are saved to `.squad/team.md` and agent directories automatically.

> **Tip:** The team file is version-controlled Markdown — commit it alongside your code.
