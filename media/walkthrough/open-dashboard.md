# The Dashboard

The Squad Dashboard gives you a real-time overview:

- **Health Score** — overall squad effectiveness (0-100)
- **Agent Status** — who's idle, active, or blocked
- **Activity Feed** — recent actions across all agents
- **Quick Stats** — tasks completed, error rate, decisions made

The health score weighs three factors:
- **Utilization** (40%) — are agents being used?
- **Error Rate** (35%) — how often do tasks fail?
- **Freshness** (25%) — when was the last activity?
