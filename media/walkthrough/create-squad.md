# Create Your Squad

Pick a template to scaffold your `.squad/` directory instantly:

| Template | What You Get |
|----------|-------------|
| **Full-Stack AI Team** | Coordinator + Backend + Frontend + @copilot |
| **Code Review Squad** | Reviewer + Security Agent + @copilot |
| **Solo + Copilot** | Just you and @copilot |
| **Empty Squad** | Blank slate — add agents yourself |

Each template creates:
- `.squad/team.md` — your team roster (Markdown table)
- `.squad/agents/` — per-agent directories with charter & history files
- `.squad/decisions/` — decision log

> **Tip:** The team file is plain Markdown. You can edit it directly or use Squad commands.
